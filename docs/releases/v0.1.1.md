# Stream Micro v0.1.1

## Changes

- Hide Windows consoles for background Codex app-server and shared
  OpenCode/OpenChamber port discovery. Explicit interactive Claude Code and
  Antigravity session-resume terminals remain available.
- Make OpenCode opt-in on new installations, with no preassigned Session keys.
  Add it through Configuration → Add a service, then assign its keys. Existing
  saved services and layouts are preserved.
- Rediscover OpenCode after a server disconnect or port change, and show a
  waiting state while its server is unavailable.
- Group CLIProxyAPI and Custom JSON API under Other, without a billing badge.
  Configured services in the add dialog now say Added rather than Connected.
- Update Vite and its locked build dependencies to resolve dependency advisories.
- Make the frozen-startup assertion independent of the temporary directory name
  and use a CJK test character shared by Traditional/Simplified Chinese fonts.

## Windows download and upgrade

Download `stream-micro-0.1.1-win64.zip`, extract it, and run `StreamMicro.exe`.
To upgrade, exit Stream Micro from its tray menu, extract the new package over
the existing installation, and relaunch. Keep `bridge.yaml` and `.state/`;
the release package does not contain user configuration, credentials or logs.

CLIProxyAPI uses HTTPS by default. An HTTP endpoint requires explicit opt-in
in the local settings; this release does not enable HTTP globally.
